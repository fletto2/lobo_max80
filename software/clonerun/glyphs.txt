; Clone Runner's glyphs, our own art. tools/glyphs.py turns them
; into build/glyphs.inc. # is a lit dot, . a dark one.
;
; "text C" is a letter, code C in ASCII, in font RAM 1: 7 rows of 5
; dots, drawn in columns 1-5 and rows 0-6 of the 8 x 8 cell, so the
; letters have a gap between them. "space" is the blank.
;
; "tile NAME CODE" is a tile, 16 x 8 dots, two cells: the left half at
; code CODE (hex) and the right half at CODE + 1. In font RAM 2 the
; codes run up from 80h with no gaps. The holes are in font RAM 1, from
; 60h, above the text, to leave font RAM 2 for the figures.
;
; "figure NAME" is one shape of a moving figure, 16 x 8 dots. Each frame
; the game draws the figure over the tiles under it into 6 glyphs of its
; own, through a mask: the figure's dots widened by one dot each side.
; "figure NAME mirror OTHER" is OTHER drawn the other way round. Each
; figure also gets a guard's shape, g_NAME, made by tools/glyphs.py: the
; same with its top row widened 2 dots each side into a hat. The
; running frames face right, their mirrors left. Their order matters to
; clonerun.asm: run0 to run3, runl0 to runl3, climb0 and climb1, hang0
; and hang1 each follow on.
